# Inventory Demand Forecasting

A machine learning project that predicts inventory demand using historical sales data and feature engineering techniques.

## Features
- Sales Forecasting
- Holiday Detection
- Weekend Analysis
- Seasonal Feature Engineering
- Multiple ML Model Comparison

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib
- Seaborn

## Machine Learning Models
- Linear Regression
- XGBoost Regressor
- Lasso Regression
- Ridge Regression

## Feature Engineering
- Weekend detection
- Weekday extraction
- Holiday identification
- Cyclical month encoding

## Evaluation Metric
- Mean Absolute Error (MAE)

## Project Structure

```bash
inventory-demand-forecasting/
```

## Dataset
The project uses historical store demand data for forecasting future inventory requirements.
